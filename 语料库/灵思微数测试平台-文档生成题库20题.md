# 一、Excel 生成（E1-E4）

## E1 基础｜工资表

**类型**：文档生成　**标题**：Excel-月度工资表

```
生成一份 2026 年 8 月工资表 Excel，文件名"2026年8月工资表.xlsx"，要求：
1. 唯一工作表"工资明细"，列依次为：工号、姓名、部门、基本工资、绩效工资、考勤扣款、应发工资、社保个人部分、个税、实发工资；
2. 数据 12 行：部门覆盖"技术部(5人)、市场部(4人)、行政部(3人)"，工号格式为部门拼音首字母+三位序号（如 JS001），基本工资 8000-25000 区间，绩效工资为基本工资的 10%-30%；
3. 应发工资、实发工资两列必须使用 Excel 公式（应发=基本+绩效-考勤扣款；实发=应发-社保-个税），不允许写死数值；
4. 社保个人部分统一按应发工资的 10.5% 计算（公式），个税列手工填 0-800 之间的合理整数；
5. 第 13 行为合计行，"合计"二字加粗，各金额列用 SUM 公式；
6. 所有金额列：千分位、两位小数、右对齐；表头行深蓝底白字加粗，全表加细边框；
7. 考勤扣款列中，数值大于 0 的单元格自动显示红色字体（条件格式）。
```

**验收点**：①公式非硬编码（抽查应发/实发单元格是公式）②条件格式生效 ③合计公式 ④格式四要素（千分位/表头/边框/对齐）⑤工号命名规则。

## E2 进阶｜进销存

**类型**：文档生成　**标题**：Excel-进销存台账

```
生成一份进销存管理 Excel，文件名"进销存台账.xlsx"，共 3 个工作表：
1. Sheet"商品档案"：10 个 SKU，列=SKU编码(SP001-SP010)、商品名称、类别(饮料/零食/日化三类)、单位、期初库存、采购单价、零售单价；
2. Sheet"流水记录"：8 月 1 日-10 日的出入库流水 30 行，列=日期、单号(RK开头为入库/CX开头为出库)、SKU编码、数量(入库为正)、经办人；同一 SKU 至少有 3 条流水，且任一 SKU 不能出现出库后库存为负的情况；
3. Sheet"库存汇总"：每 SKU 一行，列=SKU编码、商品名称、期初库存、入库总量、出库总量、期末库存、库存金额；其中商品名称用 VLOOKUP 从商品档案取，入库/出库总量用 SUMIF 从流水记录算，期末库存=期初+入库-出库（公式），库存金额=期末库存×采购单价（公式）；
4. 库存汇总表中，期末库存低于 20 的行整行浅黄色填充（条件格式或手工标出均可，但需在表下方注明"黄色为需补货商品"）；
5. 三个表表头统一深灰底白字，冻结首行。
```

**验收点**：①VLOOKUP/SUMIF 公式真实存在且结果正确 ②流水与汇总数据对得上（抽查 2 个 SKU 手工验算）③无负库存 ④冻结首行。

## E3 高压｜项目预算

**类型**：文档生成　**标题**：Excel-年度项目预算

```
1. Sheet"预算明细"：列=费用类别(一级)、费用项目(二级)、Q1、Q2、Q3、Q4、全年合计、占比；一级类别 4 个（品牌推广、渠道费用、市场活动、差旅行政），每个一级类别下 3-4 个二级项目，共 14 个项目；每行季度金额 0.5 万-40 万之间（单位：万元，两位小数）；全年合计=四个季度之和（公式）；占比=该项目全年合计/总预算（公式，百分比格式一位小数）；
2. 一级类别行需有小计（SUM 公式）并加粗浅灰底；
3. Sheet"季度分析"：用公式引用预算明细的小计行，生成"类别×季度"矩阵，并在该 Sheet 插入一个簇状柱形图（X 轴为季度，系列为 4 个类别，图表标题"2026 市场费用季度分布"）；

```

**验收点**：①图表真实存在且数据源正确 ②占比合计=100% ③小计行格式 ④跨表引用公式 ⑤单位一致。

## E4 极限｜简易损益表

**类型**：文档生成　**标题**：Excel-月度损益表

```
生成一份 2026 年 1-6 月简易损益表 Excel，文件名"2026H1损益表.xlsx"：
1. Sheet"损益表"：行项目依次为 营业收入、营业成本、毛利、销售费用、管理费用、研发费用、营业利润、营业外收支、利润总额、所得税(按利润总额25%)、净利润；列为 1-6 月+上半年合计，共 7 个数据列；
2. 营业收入 1-6 月分别为 320、285、360、410、395、450（万元），营业成本约为收入的 55%-62%（各月不同），费用类为合理正数；
3. 毛利、营业利润、利润总额、所得税、净利润、合计列必须全部为公式（毛利=收入-成本；营业利润=毛利-三项费用；净利润=利润总额-所得税；合计列=SUM）；
4. 表内加一列"净利率"（净利润/营业收入，百分比公式，一位小数）；
5. 净利润行为负数的月份（如有）自动红字；表底加一行数据校验："勾稽校验"单元格显示 =IF(净利润合计=利润总额合计-所得税合计,"平衡","错误")；
6. Sheet"趋势图"：插入折线图，系列为营业收入与净利润，X 轴 1-6 月，带数据标签；
7. 全表万元单位、两位小数，表头合并单元格写"2026年上半年损益表（单位：万元）"，二级表头为月份。
```

**验收点**：①勾稽校验显示"平衡" ②全链路公式（改动某月收入，净利润和图表应联动）③合并表头 ④折线图双系列带标签 ⑤所得税=25% 公式。

## 使用建议（不录入平台）

1. **录入字段**：类型按题头标注（E/P/W/D 用"文档生成"，Wb 用"代码生成"），标题、题干直接粘贴；验收点不录入，评分时对照。
2. **横向对比方法**：每题按统一评分表打 10 分，同难度档直接比总分；建议同时记录"生成耗时"和"一次通过率"（不修改直接可用的比例）。
3. **难度档定位**：基础=及格线（不达标的模型直接淘汰）；进阶=商用合格线；高压=旗舰模型分水岭；极限=拉开差距用（尤其 W4/D4/Wb4）。
