# 灵思微致测试平台 · 部署说明(v2.22.0)

## 包形态

| 包 | 内容 | 目标机要求 |
|---|---|---|
| `*_full.tar.gz` | 完整源码(含前端 dist、pi 依赖、go vendor) | 仅 Go 1.23+ 工具链,全程零联网即可编译 |
| `*_linux-amd64_bin.tar.gz` | 编译好的二进制(含前端)+ pi 执行器 | 直接运行,无需编译 |

启动:`./hwtest -addr 0.0.0.0:8080`(或 `bash restart.sh` 后台重启)。
首次启动控制台打印初始登录密码,登录后强制改密。

## 质量测试(pi 智能体)环境

pi 智能体用于能力/质量题的工具调用与真实文件生成(Excel/PPT/Word/PDF/网页)。
平台内置版本:pi-agent-core / pi-ai **0.84.2**,pi-goal **0.54.0**(依赖已随包内置,设置页可见版本号)。

pi 运行环境二选一:

### 方案一:Docker 沙箱(推荐)

目标机安装 Docker,然后构建一次沙箱镜像:

```bash
bash deploy/pi/build_image.sh   # 构建 hwtest-pi:local(node22 + python3 + 文档生成库 + 中文字体)
```

之后每个质量任务在独立容器内执行:文件系统隔离(看不到其他任务的残留数据),
任务结束容器自动销毁,产物收回平台数据目录。

设置页「pi 沙箱」:自动(默认)/ 强制容器 / 宿主机执行。

### 方案二:宿主机 Node 执行(无 Docker 时)

目标机安装 Node.js 18+ 即可,平台直接调本机 node 执行 pi。
注意:此模式不做文件系统隔离(任务间目录相互可见),并需自行安装文档生成依赖:

```bash
pip3 install reportlab openpyxl python-pptx python-docx matplotlib
```

## 常用端口

- 平台 Web:8080(可用 `-addr` 改)
- 被测模型服务:平台通过任务里的 API 地址访问(OpenAI 兼容 /v1/chat/completions)
